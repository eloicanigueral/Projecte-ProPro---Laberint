Detailed Description

Modul per gestionar la memoria dels personatges.

Es el nombre de sales que els personatges recorden. A mesura que avancin espais, deixaran de recordar les primeres.

Invariant
La memoria pot augmentar en el cas dels àliens.
Cada personatge té una capacietat de memòria diferent.
