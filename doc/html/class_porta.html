Detailed Description

Classe per gestionar les portes del laberint.

Representa una porta del laberint que connecta dos espais: tant una sala i un passadís, una sala amb una altre sala, o una sala i l'exterior.

Cada porta pot tenir pany en un costat o a tots dos i només es podrà obrir amb la clau corresponent.

Quan un personatge passa per una porta es tancarà automaticament. En el cas que el personatge sigui el clauer (nou personatge) la porta es mantidrà oberta un nombre de moviments, i durant aquest temps tots els personatges podràn passar encara que no tinguin la clau de la porta.

Encara que estigui oberta el sentit de pas serà el mateix (només s'entra per on hi ha el pany).
