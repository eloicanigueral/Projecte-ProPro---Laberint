Detailed Description

Modul per gestionar les smart glasses.

Aquestes ulleres son un item molt útil pels humans, ja que serveix per trobar el camí més ràpid per arribar a la sortida. S'ha de tenir en compte que aquestes no tenen en compte els espais perillosos, ni les claus que el personatge pugui tenir, així que no sempre serà possible ni òptim seguir la ruta proposada per les ulleres.
